# Grow Sessions Product Specification

## Purpose

Grow Sessions is the canonical product experience for recording active workflows, evidence, outcomes, and session history.

## Future Specification Scope

Future product specifications may define session creation, method-aware progression, current actions, history, completion, evidence review, empty states, and responsive behavior.

## Foundation Relationship

Grow Sessions specifications must follow the [Grow Foundation](../../foundation/README.md) and preserve canonical evidence ownership. Deferred context concepts should reference [Growing Conditions](../../foundation/foundation-notes/FN-001-growing-conditions.md) rather than being redefined here.
