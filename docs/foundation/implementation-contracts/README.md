# Implementation Contract Registry

## Purpose

This registry provides complete hierarchy-wide discoverability for all tracked
Grow Implementation Contracts.

Each Implementation Contract remains the sole authority for its own identifier,
title, status, scope, prerequisites, implementation boundary, exclusions, and
next authorized stage.

This registry is repository-integration evidence only. It is not canonical
Foundation truth, Product authority, implementation authority, migration
authority, or deployment authority.

Its location beneath `docs/foundation/` does not transfer ownership of a
Platform-owned, Product-owned, shared, or cross-Product capability to the Grow
Foundation.

Capability-specific references remain supplemental and may provide local
discoverability without replacing this complete registry or creating duplicate
contract authority.

This registry was established prospectively. It does not claim that complete
Implementation Contract registry coverage existed historically. Git history
remains authoritative for when each contract and prior index relationship
became attributable.
